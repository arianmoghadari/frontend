# گزارش جامع فایل‌های پوشه City List

## بررسی کلی
پوشه `city list` شامل فایل‌های مختلفی برای مدیریت و نمایش صفحات شهرها است. این سیستم از دو رویکرد استفاده می‌کند:
1. **صفحات فیزیکی** (فایل‌های HTML جداگانه برای هر شهر)
2. **صفحات پویا** (ایجاد خودکار صفحات بر اساس پارامترهای URL)

---

## فایل‌های اصلی و عملکرد آنها

### 1. فایل‌های اصلی سیستم

#### `city.html` - صفحه اصلی شهر
- **عملکرد**: صفحه پایه برای نمایش بیلبوردهای شهر
- **ویژگی‌ها**: 
  - تشخیص خودکار شهر از URL یا data attribute
  - نمایش تعداد بیلبوردها
  - فیلتر کردن بیلبوردها بر اساس شهر
  - قابلیت افزودن به سبد خرید
- **وضعیت**: ✅ **ضروری** - فایل اصلی سیستم

#### `city-script.js` - اسکریپت اصلی
- **عملکرد**: منطق اصلی نمایش صفحات شهر
- **ویژگی‌ها**:
  - تشخیص شهر از query parameter یا filename
  - بارگذاری بیلبوردها از localStorage
  - فیلتر کردن بر اساس شهر
  - ایجاد صفحات شهر در صورت عدم وجود
  - مدیریت سبد خرید
- **وضعیت**: ✅ **ضروری** - قلب سیستم

#### `city-style.css` - استایل‌های شهر
- **عملکرد**: استایل‌های مخصوص صفحات شهر
- **ویژگی‌ها**:
  - طراحی کارت‌های بیلبورد
  - استایل‌های header و summary
  - طراحی responsive
  - استایل‌های popup و cart
- **وضعیت**: ✅ **ضروری** - طراحی صفحات

#### `city-dynamic.html` - صفحه پویا
- **عملکرد**: صفحه برای نمایش محتوای پویا بر اساس پارامترهای URL
- **ویژگی‌ها**:
  - تشخیص شهر از query parameter
  - بارگذاری محتوای شهر از localStorage
  - مدیریت خطا در صورت عدم وجود شهر
- **وضعیت**: ✅ **ضروری** - برای سیستم پویا

---

### 2. فایل‌های مدیریت صفحات

#### `city-page-generator.js` - تولیدکننده صفحات
- **عملکرد**: تولید محتوای HTML برای صفحات شهر
- **ویژگی‌ها**:
  - تولید HTML برای شهرهای مختلف
  - ذخیره در localStorage
  - مدیریت شهرهای فعال
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه city-script.js

#### `city-page-manager.js` - مدیریت‌کننده صفحات
- **عملکرد**: مدیریت کامل صفحات شهر
- **ویژگی‌ها**:
  - ایجاد صفحات جدید
  - دانلود فایل‌های HTML
  - حذف صفحات
  - لیست کردن صفحات موجود
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه city-page-generator.js

#### `city-page-server.js` - سرور صفحات
- **عملکرد**: ایجاد صفحات در صورت درخواست
- **ویژگی‌ها**:
  - تشخیص URL و ایجاد صفحه مناسب
  - مدیریت خطاها
  - بارگذاری اسکریپت‌ها
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه city-script.js

---

### 3. فایل‌های ابزار و تست

#### `auto-create-pages.html` - ایجاد خودکار صفحات
- **عملکرد**: رابط کاربری برای ایجاد صفحات شهر
- **ویژگی‌ها**:
  - بارگذاری شهرها از localStorage
  - ایجاد صفحات برای همه شهرها
  - دانلود فایل‌های HTML
  - نمایش پیشرفت
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه dynamic-city-router.html

#### `dynamic-city-router.html` - مسیریاب پویا
- **عملکرد**: مسیریابی و ایجاد صفحات شهر
- **ویژگی‌ها**:
  - بارگذاری شهرها
  - ایجاد صفحات
  - تست صفحات ایجاد شده
  - راهنمای استفاده
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه auto-create-pages.html

#### `create-physical-pages.js` - ایجاد صفحات فیزیکی
- **عملکرد**: اسکریپت برای ایجاد فایل‌های HTML فیزیکی
- **ویژگی‌ها**:
  - ایجاد فایل برای هر شهر
  - دانلود خودکار
  - مدیریت تاخیر بین دانلودها
- **وضعیت**: ⚠️ **تکراری** - عملکرد مشابه سایر فایل‌ها

---

### 4. فایل‌های شهرهای موجود

#### فایل‌های HTML شهرها:
- `تهران.html` - صفحه کامل تهران با navbar و فیلتر
- `اصفهان.html` - صفحه ساده اصفهان
- `شیراز.html` - صفحه ساده شیراز
- `مشهد.html` - صفحه ساده مشهد
- `تبریز.html` - صفحه ساده تبریز
- `پردیس.html` - صفحه ساده پردیس

**وضعیت**: ✅ **ضروری** - صفحات شهرهای موجود
