# سیستم مدیریت تابلوهای تبلیغاتی

یک سیستم کامل مدیریت تابلوهای تبلیغاتی با پنل کاربری و سطوح دسترسی مختلف.

## ویژگی‌های سیستم

### 🎯 صفحات اصلی
- **صفحه اصلی** (`navbar.html`) - ناوبری و منوی اصلی
- **جدول تابلوها** (`billboards-table.html`) - مدیریت و نمایش تابلوهای تبلیغاتی
- **پروفایل کاربر** (`profile.html`) - نمایش و ویرایش اطلاعات کاربر
- **پنل مدیریت** (`admin-panel.html`) - مدیریت کاربران و تنظیمات سیستم

### 👤 سیستم کاربری
- **پروفایل کاربری** با نمایش اطلاعات کامل
- **سطوح دسترسی** مختلف (مدیر کل، مدیر، کاربر عادی)
- **مدیریت کاربران** با قابلیت افزودن، ویرایش و حذف
- **تاریخچه فعالیت‌ها** و گزارش‌گیری

### 🎨 طراحی و رابط کاربری
- **طراحی مدرن** با Glassmorphism
- **ریسپانسیو** برای تمام دستگاه‌ها
- **پشتیبانی از RTL** (راست به چپ)
- **انیمیشن‌های روان** و تعاملی
- **سیستم اعلان‌ها** برای بازخورد کاربر

## ساختار فایل‌ها

```
navbar/
├── navbar.html              # صفحه اصلی با ناوبری
├── billboards-table.html    # صفحه جدول تابلوها
├── profile.html             # صفحه پروفایل کاربر
├── admin-panel.html         # پنل مدیریت
├── style.css                # استایل‌های اصلی ناوبری
├── main.css                 # استایل‌های پایه
├── table-style.css          # استایل‌های جدول
├── profile-style.css        # استایل‌های پروفایل
├── admin-style.css          # استایل‌های پنل مدیریت
├── javas.js                 # اسکریپت ناوبری
├── table-script.js          # اسکریپت جدول
├── profile-script.js        # اسکریپت پروفایل
├── admin-script.js          # اسکریپت پنل مدیریت
└── README.md               # راهنمای استفاده
```

## نحوه استفاده

### 1. شروع کار
- فایل `navbar.html` را در مرورگر باز کنید
- از منوی ناوبری برای دسترسی به بخش‌های مختلف استفاده کنید

### 2. مدیریت تابلوها
- روی "جدول کل تابلوها" کلیک کنید
- از فیلترها و جستجو برای یافتن تابلوهای مورد نظر استفاده کنید
- دکمه "افزودن تابلو" برای اضافه کردن تابلو جدید

### 3. پروفایل کاربر
- روی آواتار کاربر در ناوبری کلیک کنید
- "پروفایل" را انتخاب کنید
- اطلاعات شخصی، سطح دسترسی و آمار فعالیت را مشاهده کنید
- دکمه "ویرایش پروفایل" برای تغییر اطلاعات

### 4. پنل مدیریت
- از منوی کاربری "پنل مدیریت" را انتخاب کنید
- **مدیریت کاربران**: افزودن، ویرایش و حذف کاربران
- **سطوح دسترسی**: مدیریت نقش‌ها و مجوزها
- **تنظیمات سیستم**: تغییر تنظیمات امنیتی و اعلان‌ها
- **گزارش فعالیت‌ها**: مشاهده تاریخچه فعالیت‌های سیستم
